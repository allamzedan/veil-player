# What is VEIL?

VEIL is a professional, local-first, non-destructive media layer.

It allows people to customize how they experience video and audio without ever modifying the original media.

The original file always remains untouched.

A VEIL file stores viewing instructions only.

---

# Vision

Give every viewer complete control over how media is experienced while preserving the original source forever.

VEIL should become the universal viewing layer that can sit on top of any supported media.

---

# Mission

Build the world's best non-destructive media experience.

Not the biggest.

Not the most complicated.

The most trustworthy.

---

# Core Philosophy

## Non-destructive

VEIL never edits, rewrites, converts, or damages source media.

Everything exists as an independent .veil layer.

---

## Local First

Media belongs to the user.

VEIL works offline.

No mandatory cloud.

No accounts.

No subscriptions.

No internet required.

---

## Privacy First

No telemetry.

No hidden analytics.

No advertising.

No tracking.

No user profiling.

---

## Fast

Opening a video should feel instant.

Large VEIL files should remain responsive.

Performance is a feature.

---

## Professional

VEIL should feel like software such as:

• VS Code
• DaVinci Resolve
• Figma
• Affinity

Not like a web page running inside Electron.

---

# What VEIL Is NOT

VEIL is not:

- A video editor
- A transcoder
- A converter
- A streaming service
- A cloud platform
- A social network
- A media library manager
- An NLE
- DRM software

Those problems are intentionally outside VEIL's scope.

# Long-Term Goals

VEIL should become the reference application for non-destructive media customization.

Future capabilities may include:

- Universal media support
- Audio workflows
- Advanced subtitle workflows
- Learning tools
- Accessibility tools

These additions must never violate the core philosophy.

---

# Success Criteria

A successful VEIL release:

- Never modifies source media.
- Opens quickly.
- Feels native.
- Is understandable by non-technical users.
- Is powerful for advanced users.
- Remains trustworthy.
- Can be used completely offline.

---

# Decision Rule

Every future feature must answer one question:

"Does this strengthen VEIL as a non-destructive media layer?"

If the answer is no, the feature should be rejected or reconsidered.
