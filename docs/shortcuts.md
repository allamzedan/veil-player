# Keyboard shortcuts

See in-app **Help → Shortcuts** or press **?** for the live list.

## Playback

| Key | Action |
|-----|--------|
| Space | Play / pause |
| R | Smart replay |
| Shift+R | Fixed replay |
| Shift (hold) | Peek subtitles (Smart Cover) |
| V | Brief reveal |
| [ / ] | Speed down / up |
| F | Fullscreen |

## Subtitles

| Key | Action |
|-----|--------|
| Alt+← / Alt+→ | Previous / next cue |
| Alt+R | Repeat current cue |

## Track

| Key | Action |
|-----|--------|
| M / U / K | Add mask / mute / skip |
| I / O | Set start / end at playhead |
| Del | Delete selected |
| Ctrl+S | Save track |

## UI

| Key | Action |
|-----|--------|
| ? | Shortcut help |
| Ctrl+Z / Ctrl+Y | Undo / redo |
