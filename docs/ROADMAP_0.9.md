# VEIL 0.9 Roadmap
Status: Active
Target: Public Beta

---

# Goal

VEIL 0.9 transforms the application from a feature-complete prototype into a professional desktop product ready for public beta.

This phase prioritizes polish, reliability, performance, and usability over adding entirely new concepts.

The focus is making VEIL trustworthy.

---

# Release Objectives

✓ Stable

✓ Fast

✓ Professional

✓ Predictable

✓ Local-first

✓ Ready for real users

---

# Milestone R12 — Universal Media Foundation

Purpose

Support the media formats users expect from a modern desktop player.

Deliverables

• Universal media compatibility audit

• Improve seek reliability

• Robust metadata handling

• Audio playback support

• Video playback support

• Better media error reporting

Target formats

Video

✓ MP4

✓ MKV

✓ AVI

✓ MOV

✓ MPEG

✓ MPG

✓ WEBM

✓ TS

✓ M2TS

✓ OGV

✓ VOB

✓ WMV

✓ FLV (best effort)

✓ 3GP

Audio

✓ MP3

✓ WAV

✓ FLAC

✓ AAC

✓ OGG

✓ M4A

Acceptance

Opening media should feel immediate.

Seeking should feel instant.

Playback should remain smooth.

Deliverables

• Unified toolbar

# Bug Fix Policy

Bugs may interrupt roadmap work only if they are:

Critical

Major

Regression

Data-loss

Performance

Otherwise they are scheduled.

---

# Feature Freeze

No unrelated features may enter 0.9.

Examples deferred:

AI

OCR

Cloud

Online accounts

Streaming

Subtitle OCR

Translation

These belong after 1.0.

---

# Definition of Done

A milestone is complete only when:

✓ Code complete

✓ Tests pass

✓ Manual QA complete

✓ Documentation updated

✓ Manifest still respected

✓ Design System still respected

✓ Git committed

✓ Git tagged

✓ Portable build created

✓ Installer verified (where applicable)

---

# Exit Criteria

VEIL 0.9 Beta is released when:

• Major features complete

• UI polished

• Performance acceptable

• No critical regressions

• Installer ready

• Documentation complete

Only then does development move to VEIL 1.0.
